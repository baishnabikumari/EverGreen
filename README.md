# Evergreen Decorator (decorate your christmas tree)

**Evergreen** is an interactive game where you can decorate a low-poly christmas tree in a snowy winter(snowfall).

## **Tools**
-- Three.js, js (core es6 module)

## features
1. **3d environment (Used a tree 3d modal from Sketchfab)**
2. **decoration mode with buttons using the right bottom gift menu**
3. **Live Snow fall**
4. **Delete mode(use the dustbin icon on the right up side)**
5. **screenshot mode( YOu can take snapshot after decorating the tree)**

## New things added
> **Added a deselect function - where you can deselect an item by clicking it again on that same button so will return to the view only mode from edit mode.**

> **Added new sound to the game when the game start then if the user click anywhere or may click on any button the song starts playing and if the song gets over it will start again.**

##

## How to play
1. Loading-- wait for 4sec
2. To take a view of 3d tree(rotate around tree use left click + drag OR Zoom in/ Out)
3. Decorate the tree by using balls palette or use the gift button on bottom right - that gift box will open 3 button for STARS, BALLS and GIFT BOXES.
4. Trash(bin icon)- delete the entire decoration.
5. Camera icon- take a shot of your decoration.
